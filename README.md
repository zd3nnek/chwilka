# Chwilka

Spokojne zabawy, ciekawostki o świecie i bajki na dobranoc dla dzieci w wieku 2–6 lat.

**Strona:** https://chwilka.app

## Pobierz

Najnowszy plik **Chwilka.apk** (Android) jest w zakładce [Releases](https://github.com/zd3nnek/chwilka/releases/latest).

Bez reklam i bez czatu. Wszystko, co wpiszesz, zostaje w telefonie. Szczegóły: [polityka prywatności](https://chwilka.app/prywatnosc).
